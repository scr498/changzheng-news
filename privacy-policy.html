长征记忆 · 隐私政策

重走长征路 · 红色文化学习应用
最后更新日期：2026年7月29日

感谢您使用「长征记忆」应用（以下简称"本应用"）。我们非常重视您的隐私保护。本政策说明本应用如何收集、使用和保护您的信息。请您在使用前仔细阅读。

核心承诺：本应用不收集、不上传任何用户个人信息。您的学习进度、答题记录、收藏、令牌、录音文件等所有数据均仅存储在设备本地（应用沙箱），不会传输至任何服务器。

一、我们如何收集和使用您的个人信息

本应用不收集、不上传任何用户个人信息。所有用户数据均在设备本地处理与存储，不会传输至任何服务器。

✓不收集姓名、电话、邮箱、身份证等任何个人信息
✓不上传任何用户数据至服务器或第三方
✓仅本地处理与存储全部用户数据
✓可撤回所有敏感权限，随时在系统设置中关闭

本应用不会收集您的设备标识符、网络身份标识、个人基本信息、位置信息等任何可用于识别您个人身份的数据。

二、系统权限说明

为保障功能正常运行，本应用会按需申请以下系统权限。所有权限均在使用对应功能时动态申请，您可随时在系统设置中撤回授权；撤回后相关功能不可用，但不影响其他功能。

权限对应功能用途说明数据处理方式
网络（INTERNET） 红色档案 / 红色资讯 / 影音推荐 / AI对话 访问在线公开内容、拉取资讯与视频列表、AI对话请求 仅拉取公开内容，不上传个人信息
麦克风（MICROPHONE） 语音搜索 / 朗诵录音 / 语音识别 录制用户朗诵音频用于本地回放；识别用户语音转为文字用于搜索 音频仅在本地处理与存储，不上传
运动与健身（ACTIVITY_MOTION） 重走长征路 读取设备步数，计算虚拟行军里程 仅本地计算
读写媒体文件（WRITE_IMAGEVIDEO） 保存图片 / 导出学习报告 将应用内图片、学习报告等文件保存至设备相册或文件系统 仅本地读写，不上传

三、数据本地化存储

本应用所有用户数据均在设备本地处理与存储，包括但不限于：

  • 学习记录：已学章节进度、答题得分与完成情况
  • 令牌与成就：已获得令牌数量与成就徽章
  • 收藏内容：用户收藏的文章与资料
  • 虚拟行军数据：步数统计与行军里程
  • 录音文件：朗诵录音音频文件
  • 隐私同意记录：是否已同意隐私政策

您可随时通过「系统设置 → 应用管理 → 长征记忆 → 存储 → 清除数据」删除全部本地数据，或通过卸载应用彻底清除。

四、AI 智能对话

本应用的「AI 对话」功能由第三方服务商「智谱 GLM（Zhipu AI）」提供。当您使用 AI 对话时，您输入的问题文本与对话内容会通过网络发送至智谱 GLM 云端进行处理并生成回复。

请注意：

  • 我们不会在对话内容中附加您的个人身份信息
  • 请您避免在对话中透露姓名、电话、住址、身份证号等敏感个人信息
  • 智谱 GLM 的隐私政策详见 https://open.bigmodel.cn/privacy
  • 您可随时在应用内「设置」中更换或清空所使用的 API Key

五、第三方服务

本应用可能包含第三方链接（如纪念馆官网、新闻来源网站等），这些网站有各自的隐私政策，建议您查阅其政策内容。

  • 内容托管：本应用的公开内容（资讯、档案、视频列表等）通过 GitHub Pages / jsDelivr CDN 分发，均为公开信息，不涉及个人信息收集。
  • AI 服务：智谱 GLM（Zhipu AI）—— 详见第四节。
  • 在线视频：本应用中的视频内容可能由第三方平台托管，访问时受该平台隐私政策约束。

六、儿童隐私

本应用主要面向党史学习教育与爱国主义教育场景，内容健康向上，适合各年龄段用户。若涉及儿童独立使用，请在监护人指导下使用，涉及权限授权时建议由监护人确认。

七、用户隐私权利

本应用不收集、不上传任何个人信息。基于本地存储的特性，用户享有以下权利：

  1. 访问与删除：可随时在应用内清除本地数据，或通过卸载应用删除全部本地信息。
  2. 权限撤回：可随时在系统设置中撤回已授予的权限，撤回后相关功能不可用，但不影响其他功能。
  3. 咨询与投诉：如对隐私事宜有疑问，可通过本政策"联系我们"中的方式与我们联系。

八、隐私政策的更新

我们可能会适时更新本隐私政策。更新后的版本将在本页面发布并更新"最后更新日期"。重大变更时，我们会在应用内以弹窗或公告形式通知您。
